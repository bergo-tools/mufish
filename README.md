# 木鱼进销存（Mufish）

面向贸易型小企业的**单机进销存软件**。一个可执行文件、一个 SQLite 文件，双击即用，无需安装数据库、无需联网。

```
┌──────────────────────────────────────────────┐
│            木鱼进销存  Mufish                │
└──────────────────────────────────────────────┘
```

## 特性

- **单文件部署**：前端资源通过 `go:embed` 打进二进制，运行时不依赖任何外部文件；SQLite 驱动为纯 Go 实现（modernc.org/sqlite），`CGO_ENABLED=0` 即可交叉编译。
- **单机优先**：数据全部保存在本地 SQLite 文件中（WAL 模式），单连接串行写入，杜绝锁冲突；默认只监听 `127.0.0.1`。
- **简单权限系统**：基于角色的访问控制（RBAC），内置 7 个角色、46 个细粒度权限点，可为每个角色自由勾选；菜单与操作按钮随权限自动显隐，后端逐接口二次校验。
- **完整的基础进销存**：商品 / 分类 / 往来单位 / 仓库 / 资金账户、采购入库、销售出库、库存查询与流水、库存预警、库存盘点、库存调拨、收付款与应收应付、多维度统计报表。
- **移动加权平均成本**：所有出入库统一走库存引擎，自动计算结存成本与销售毛利。
- **单据全生命周期**：草稿 → 确认（真正影响库存 / 资金）→ 作废（自动冲销库存与账务），已确认单据不可直接删除，保证账实可追溯。
- **操作日志**：登录、增删改、确认、作废、备份恢复等关键动作全部留痕。

## 技术栈

| 层 | 选型 |
| --- | --- |
| 后端 | Go 1.24+（标准库 `net/http`，Go 1.22+ 路由模式） |
| 数据库 | SQLite（modernc.org/sqlite，纯 Go，无 CGO） |
| 前端 | Preact 10 + 原生 Fetch，esbuild 打包 |
| 前端构建 | Node.js 18+ / npm |
| 口令散列 | `crypto/pbkdf2`（PBKDF2-SHA256，120000 轮） |
| 会话 | HttpOnly + SameSite=Strict Cookie，令牌存于 `sessions` 表 |

**后端零第三方依赖**，唯一的外部依赖是 SQLite 驱动。

## 快速开始

### 1. 构建

```bash
# 需要 Go 1.24+ 与 Node.js 18+
make            # 等价于：构建前端 → 编译出 ./mufish
```

如果只想编译后端（前端产物已存在）：

```bash
go build -o mufish .
```

### 2. 运行

```bash
./mufish                 # 默认 http://127.0.0.1:8899；Windows/macOS 自动打开浏览器
./mufish -open=false     # 不自动打开浏览器
./mufish -open           # Linux 显式开启自动打开
./mufish -addr 0.0.0.0:8899 -data /path/to/data   # 局域网共享 / 自定义数据目录
```

启动后浏览器访问 `http://127.0.0.1:8899`。

| 参数 | 默认值 | 说明 |
| --- | --- | --- |
| `-addr` | `127.0.0.1:8899` | 监听地址。想让同事在局域网访问可改为 `0.0.0.0:8899` |
| `-data` | `data` | 数据目录，存放 `mufish.db` 与 `backups/` |
| `-open` | Windows/macOS 为 `true`，Linux 为 `false` | 启动后自动打开浏览器；传 `-open=false` 可关闭 |
| `-version` | | 打印版本号 |

### 3. 登录

| 账号 | 口令 | 角色 |
| --- | --- | --- |
| `admin` | `admin123` | 系统管理员（全部权限） |
| `manager` | `admin123` | 业务经理 |
| `sales` | `admin123` | 销售员 |
| `stock` | `admin123` | 仓管员 |

> 首次登录后请立即到「个人中心」修改口令。登录页只在 `admin` 仍使用默认口令时展示初始账号提示；修改口令并退出后会隐藏提示。首次启动会自动写入一批演示用的商品、往来单位与期初库存，方便直接体验；演示数据只在数据库首次初始化时写入，如需清空，请先备份，再停止程序并删除数据目录中的 `mufish.db`（会重置全部数据，重启后重新初始化）。

| 资金往来 | 收款单 / 付款单，可关联到具体采购或销售单并校验未结金额，自动更新账户余额与单据已收 / 已付；往来冲抵无需资金账户，也不改变账户余额 |
| 统计报表 | 进销存汇总、销售排行、采购排行、客户排行、供应商排行、商品毛利、应收应付对账、销售 / 采购明细、资金流水（支持关键字搜索）；其中进销存汇总、应收应付对账支持 CSV 导出 |
| 系统管理 | 用户管理、角色权限（图形化勾选 46 个权限点）、操作日志、系统参数、数据库备份与恢复 |

## 权限模型

权限编码为 `模块:动作`，共 12 个模块 46 个权限点。角色的 `perms` 中包含 `*` 表示超级权限（内置「系统管理员」角色）。

- 前端：`can('purchase:create')` 控制菜单项与按钮显隐。
- 后端：每条路由声明所需权限，`wrap` 中间件统一校验并返回 403。
- 分类下拉是商品、库存、报表页面的基础数据，拥有 `category:view`、`product:view`、`stock:view` 或 `report:view` 任一权限即可读取。
- 内置角色不可删除，内置超级管理员账号不可删除 / 停用。
- 收款单只能选择客户，付款单只能选择供应商；修改往来单位类型时，如果会隐藏已有应收 / 应付，系统会阻止操作。
- 纯供应商不能填写期初应收，纯客户不能填写期初应付；客户兼供应商可以同时填写。首页、往来单位列表与应收应付报表使用相同的类型口径。
- 有盘点单引用的仓库不可删除，避免盘点完成时写入不存在的仓库。

## 数据与备份

- 数据库文件：`<数据目录>/mufish.db`（同时存在 `-wal`、`-shm` 文件属正常现象）。
- 内置备份：在「系统 → 数据维护」中一键备份（使用 `VACUUM INTO` 生成一致性快照），备份文件位于 `<数据目录>/backups/`，可一键恢复（恢复前会自动生成 `.before-restore` 回滚副本）。
- 资金账户余额只能通过「调账」修改，每次调账都会生成独立记录（调整前后金额、差额、原因、操作人和时间）；编辑账户资料不会改变余额。
- 手动备份：直接复制 `mufish.db`（建议先停止程序，或在程序内执行一次备份）。

## 数值精度说明

- **金额**以「分」为单位的整数存储，**单价**以「万分之一元」为单位的整数存储，**数量**为最多 4 位小数的实数。
- 对前端（JSON）统一暴露为「元」的浮点数，由 `model.Money` / `model.Price` / `model.Qty` 三个类型自动转换，业务代码不会直接接触分。
- 「数量 × 单价」先把数量和单价换算成整数再计算，按分四舍五入（负数远离零），避免 `0.7 × 0.05` 这类半分边界因浮点误差少计 1 分。
- 采购、销售、盘点、调拨页面与后端使用同一逐行取整规则：先把每行金额算到分再求和，页面合计不会与保存后的服务端合计相差 1 分。
- 出库成本采用**移动加权平均法**：入库后重算结存单价，出库按结存单价结转；作废单据时按原流水金额冲销，不会用当前平均价重新计算，避免后续入库后结存成本失真。
- 采购单的运费/其他费用默认**计入**库存成本，商业折扣默认**冲减**库存成本，按明细金额比例分摊；可在「系统参数 → 业务开关」关闭，关闭后只影响结算金额。采购现金折扣、销售运费和销售优惠不计入库存成本。

## 常见问题

**端口被占用？** 换一个端口：`./mufish -addr 127.0.0.1:9000`。

**局域网其他电脑访问不了？** 用 `-addr 0.0.0.0:8899` 启动，并在系统防火墙放行该端口。请注意：协议为 HTTP，仅建议在可信内网使用。

**忘记管理员口令？** 目前没有在线找回功能。停止程序并备份后，删除数据目录中的 `mufish.db` 会重置全部数据，下次启动重新创建 `admin / admin123`。不要只删除 `users` 表中的超级管理员记录：程序只在 `users` 表为空时初始化管理员，其他账号存在时不会重建。

**能否多台电脑共用一套数据？** 本软件按单机设计。若确需共享，可把数据目录放在网络盘上，但仅建议 1～3 人低频使用。
